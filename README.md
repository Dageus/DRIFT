# Smart Contract Implementation

## Workflow to Deploy and Test a Smart Contract

- Develop Smart Contract (in Solidity)

- Connect to Remix via `remixd`

- Analyze Smart Contract

- Run a `hardhat` node

- Compile Smart Contract

- Run Transaction in Dev Hardhat Environment (Deploy & Run Transaction > Environment > Dev > Hardhat Provider)

## Dependencies

- Foundry

- Hardhat

- OpenZeppelin
